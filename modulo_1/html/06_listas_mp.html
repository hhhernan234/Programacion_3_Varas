Requisitos para el registro de Nómina

  • Cédula de identidad del empleado
  • Contrato de trabajo firmado
  • Registro de horas laboradas
  • Cálculo de beneficios de ley
  • Certificado bancario para depósito

Lista ordenada de procesos

Pasos para generar la nómina mensual

  1. Ingresar datos personales al sistema
  2. Cargar el salario básico unificado
  3. Calcular horas extras y bonificaciones
  4. Aplicar retenciones del IESS y préstamos
  5. Generar el archivo plano para el banco
  6. Emitir el rol de pagos en PDF
  7. Archivar comprobante firmado

Seguimiento desde la fase de aprobación (Paso 5)

  1. Generar el archivo plano para el banco
  2. Emitir el rol de pagos en PDF
  3. Archivar comprobante firmado

Cronología de cierre de mes (Inversa)

  1. Archivar comprobante firmado
  2. Emitir el rol de pagos en PDF
  3. Generar el archivo plano para el banco

Categorías de empleados (Letras Alfabéticas)

  1. Personal Administrativo
  2. Personal Operativo
  3. Personal de Ventas
  4. Gerencia General

Niveles de seguridad del sistema (Números Romanos)

  1. Acceso restringido (Lectura)
  2. Nivel Intermedio (Edición)
  3. Acceso Total (Administrador)

Subtareas de auditoría (Romanos minúsculas)

  1. Verificación de firmas digitales
  2. Validación de cuentas bancarias
  3. Cruce de información con el SRI
