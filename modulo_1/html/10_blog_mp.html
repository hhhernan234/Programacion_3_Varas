¿Qué es este Sistema?

El software de CNTH es una herramienta desarrollada para la gestión contable. Cumple con los estándares del SRI y el IESS, siendo actualmente el estándar para el manejo de sueldos en el proyecto de Programación III.

La nómina no es solo un pago; es el registro legal que garantiza la transparencia entre el empleador y el colaborador, protegiendo los derechos de ambas partes.

Componentes Técnicos del Proyecto

  • Base de Datos Relacional: Tablas de empleados y roles
  • Backend en Python: Lógica de cálculos y validaciones
  • Frontend Semántico: Uso de etiquetas <main> y <section>
  • Persistencia de Sesión: Uso de tokens y cookies

Flujo de Trabajo del Contador

  1. Verificar que el empleado tenga un contrato activo
  2. Ingresar las horas extras del periodo actual
  3. Ejecutar el proceso de cálculo de retenciones
  4. Generar el archivo plano para transferencia bancaria
  5. Emitir el comprobante de pago con firma electrónica

Evolución del Registro Laboral

Método Manual vs Automatizado

Antiguamente se usaban libros contables físicos para el registro. Hoy usamos bases de datos PostgreSQL para garantizar la integridad de la información.
